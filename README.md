# Temporary AlarmX query demo

Public synthetic-only S07.1 visual query editor, original S07 demo and collapsible
screenshot guide. All query execution happens in your browser; no live AlarmX
server, devices, credentials or private repository history are included.

Do not enter private data. Query changes remain in the current tab. Appearance
preferences are stored locally in your browser. This site does not upload
interaction logs. GitHub may retain ordinary HTTP access information.

The root opens S07.1. Use the navigation links for original S07 and screenshot
help. The generated `public-assets.json` lists the demo build's public assets.
This repository contains generated publication output, not the native app.

To unpublish, use this repository's Settings > Pages > Unpublish site.
